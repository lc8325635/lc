This program is a reminder of how to get letters from a string.

The variable rle contains an RLE encoded string. This means the string consists of digit and letter pairs.

Write a program which decodes the string by reading the digit and then repeating the letter that many times.

For example, 6A1C4B -> AAAAAACBBBB

The DNA that makes up all living things can be represented as a long string of the letters A, C, G and T.

In this task, you have a section of DNA stored in the variable dna.

  • Calculate and print the percentage of total letters which are either G or C.
  • Count how many times in the string there are 3 C letters in a row ("CCC").
