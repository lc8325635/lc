List Statistics 1

In these exercises, you will work with four arrays:

  • students contains the names of 10 students in a class.
  • physics contains their scores in the physics exam.
  • chemistry contains their scores in the chemistry exam.
  • biology contains their scores in the biology exam.

The example program below displays the data.

Write a program which calculates the mean score for chemistry.

Write a program which finds the maximum score for physics.

Write a program which calculates the range of the scores in biology.

Write a program which calculates a total science score by adding all three results together. Then display the name and score of the highest scoring student.
