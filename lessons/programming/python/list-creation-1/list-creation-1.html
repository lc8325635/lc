Ask the user to enter 4 words. Then print the words in reverse order.

For example:

The user enters january february march april and the program prints april march february january.

Ask the user to enter 10 words. Then print only the words with more than 4 letters.

For example:

The user enters Dulwich is a school on Hengqin island the program prints Dulwich school Hengqin island.

Ask the user to enter 10 test scores. Each time the user enters a score, say You beat x out of y people! where x is how many of the previous scores were lower, and y is the total number of scores.

For example:

If the user has already entered the numbers 50, 33, 72 then when the user enters 65, the program should say You beat 2 out of 3 people!

Ask the user to enter 5 numbers between 1 and 10. Validate that each number is between 1 and 10. Then print all the numbers between 1 and 10 which the user did not enter.
